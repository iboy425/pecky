# Pecky Cap BLE 协议 v1

ESP32 本地完成动作识别和计数。App 只接收语义进度、持久事件与状态快照，不以原始 IMU 流或进度消息发放奖励。

## GATT

| 项目 | UUID | 属性 |
| --- | --- | --- |
| Service | `2f6f1000-8d0a-4e3d-bbc6-9f536a6ed001` | Primary service |
| EVENT | `2f6f1001-8d0a-4e3d-bbc6-9f536a6ed001` | Notify |
| SNAPSHOT | `2f6f1002-8d0a-4e3d-bbc6-9f536a6ed001` | Read, Notify |
| COMMAND | `2f6f1003-8d0a-4e3d-bbc6-9f536a6ed001` | Write, Write Without Response |

广播设备名为 `Pecky-XXXX`，其中 `XXXX` 来自 ESP32 芯片 ID。广告中包含 Service UUID。

## 字段

- `v`：协议版本，当前为 1；
- `t`：消息类型；
- `s`：设备训练会话 ID；
- `q`：持久事件序号；App 用 `(deviceId, q)` 去重；
- `r`：本组已完成次数；`g`：每组目标，当前为 3；
- `c`：动作，`1=后仰`、`2=收下巴`、`3=抱头抗阻`；
- `h`：本次候选/有效保持毫秒数；
- `a`：内部状态，`0=空闲`、`1=候选运动/施压`、`2=保持`、`3=等待回中立/释放`、`4=冷却`；
- `ph`：压力通道是否已经通过有效施压检查；
- `pt`：压力自检是否正在进行；
- `tr`：设备生命周期累计动作次数；
- `m`：设备 `millis()`；
- `cf`：识别器置信度百分数，仅用于界面和调试，不作为奖励金额。

## 消息

进度约 5 Hz，可丢失，不能驱动计数或奖励：

```json
{"v":1,"t":"p","s":12,"q":47,"r":1,"g":3,"c":3,"h":1840,"a":2,"pt":0,"m":98123}
```

一次动作完成后立即发送持久事件：

```json
{"v":1,"t":"r","s":12,"q":48,"r":2,"g":3,"c":3,"h":2040,"cf":88,"m":101234}
```

每组第 3 次完成后发送：

```json
{"v":1,"t":"x","s":12,"q":49,"r":3,"g":3,"m":101240}
```

连接、同步和每次持久事件后更新 SNAPSHOT：

```json
{"v":1,"t":"z","s":12,"q":49,"r":3,"g":3,"tr":128,"a":0,"ph":1,"pt":0,"m":101240}
```

## App 流程

1. 扫描 Service UUID，连接后订阅 EVENT 与 SNAPSHOT。
   手机端连接后必须申请 ATT MTU 至少 185；若平台无法申请，则不能假设长 JSON Notify 一定送达，必须以 Read SNAPSHOT 对账。
2. 先 Read SNAPSHOT，再写 `sync`；将本地保存的 `q` 与设备快照对账。
3. `p` 只更新动作动画和保持进度。
4. `r` 按 `(deviceId, q)` 去重后更新动作记录；`c` 决定动作名称。
5. `x` 触发整组完成动画/奖励；奖励逻辑在 App，不写死在固件。
6. 断线期间设备继续计数；重连以 SNAPSHOT 的 `q`、`tr` 为最终真相。

## COMMAND

```json
{"v":1,"cmd":"sync","after":47}
{"v":1,"cmd":"calibrate"}
{"v":1,"cmd":"reset_session"}
{"v":1,"cmd":"pressure_test"}
```

- `sync`：返回最新 SNAPSHOT；
- `calibrate`：用户保持中立不按压力片时重新做 3 秒校准；
- `reset_session`：新建会话并清空本会话次数，不清生命周期累计数。
- `pressure_test`：开启 8 秒压力自检。先完全松开压力片至少 0.5 秒，再连续按压至少 0.5 秒；通过后 `ph=1`，否则抗阻识别保持禁用，但不影响后仰和收下巴。

识别不依赖 App 的 Start。设备上电校准后自行工作；抗阻在每次上电/重新校准后需要一次明确的 `pressure_test`，避免把松线、卡高或调帽误当成有效压力。COMMAND 仅用于同步、重新佩戴后的校准、压力自检和演示会话管理。
